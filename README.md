# السيد - Version 1 🎬

مشروع مستقل لتوليد السيناريوهات والفيديوهات بالذكاء الاصطناعي، مبني على فكرة Turbo ElSayed مع تطويرات خاصة بنظام الشخصيات الثابتة والأفلام الطويلة.

## ✨ المميزات

- توليد سيناريوهات كاملة (عنوان، ملخص، شخصيات، مشاهد) بصيغة JSON منظمة.
- نظام شخصيات ثابت عبر كل المشاهد (`characters.json`).
- دعم توليد الصور والمشاهد لوضع الأفلام الطويلة.
- تكامل مع مزودات LLM متعددة.

## 📁 هيكل المشروع

| المسار | الوظيفة |
|---|---|
| `app/services/` | خدمات التوليد والمعالجة |
| `app/controllers/` | واجهات الـ API |
| `webui/` | واجهة الاستخدام الرسومية |
| `characters.json` | ملف تعريف الشخصيات الثابتة |
| `config.example.toml` | نموذج إعدادات المشروع |
